# steam-goty-analysis
Les jeux nominés aux Game Awards sont-ils aussi ceux que les joueurs Steam accueillent le mieux ? Qu’est-ce qui distingue les jeux sur lesquels critiques et joueurs sont d’accord, et ceux où ils divergent ?

Dans ce projet, on cherche à savoir si les jeux qui sont nominés pour le titre de jeu de l'année par les Games Awards sont les mêmes jeux que les joueurs sur Steam apprécient le plus. A partir de là on peut s'intéresser aux points de divergence entre les retours joueurs et ceux de la presse. Mais il faut tenir compte du fait que les Games Awards prennent en compte des jeuc de toutes les plateformes. Il faudra alors chercher les avis des joueurs sur  les différentes plateformes dont proviennent les nominés.
